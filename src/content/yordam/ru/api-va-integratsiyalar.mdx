Tasnivo связывается с другими программами тремя способами: открытый API, бот Telegram и исходный код дополнения для Google Таблиц.

## API

Администратор создаёт ключ API в разделе Настройки → Интеграции. Ключ показывается один раз; на сервере хранится только его хеш. Ненужный ключ можно отозвать в любой момент.

Через API можно:

- проверить название товара: возвращаются тип проблемы, предложенный код и альтернативы;
- получить список каталогов организации;
- загрузить каталог Excel или CSV и запустить аудит;
- получить отчёт по каталогу постранично.

Лимит запросов на один ключ: <ApiRate />; в одной проверке — до <ApiItems /> товаров. Число проверок в месяц зависит от тарифа: [Тарифы и лимиты](/yordam/ru/tariflar-va-limitlar). Полная документация и примеры: [документация API](/api-docs).

Оценка совпадения (confidence), которую возвращает API, упорядочивает кандидатов; это не вероятность того, что код верен. Код в каталоге меняется только после того, как человек примет предложение в приложении.

## Уведомления в Telegram

Администратор получает одноразовый код в разделе «Интеграции» и отправляет его боту. После этого в чат приходят результаты анализа и обновления классификатора; можно также отправить боту файл каталога, чтобы начать анализ. Чат можно отключить в любой момент. Если в разделе «Интеграции» нет блока Telegram, эта возможность для вашего аккаунта пока не подключена.

## Google Таблицы

Дополнение для Google Таблиц существует только в виде исходного кода: оно не опубликовано в каталоге Google Workspace Marketplace и не устанавливается для всех. Чтобы им пользоваться, разработчик устанавливает исходный код в таблицу через Apps Script и вводит ключ API. Каждый проверенный товар входит в лимит проверок API.
